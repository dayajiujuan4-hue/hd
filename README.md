# 杭州探索録3｜夜行杭州 Definitive Edition Ver.1.2

Ver.1.2では既存の高密度都市描画を維持したまま、地下鉄による地区間ファストトラベル、動く交通、杭州探索手帳を追加しました。

## 操作
- WASD / 矢印キー: 移動
- E: 話す / 入る / 地下鉄を利用
- J: 杭州探索手帳
- ESC: パネルを閉じる

## 地下鉄
各地区に駅入口があります。
- 钱江新城: 市民中心
- 杭州旧城区: 定安路
- 武林夜市: 武林广场
- 西湖東岸: 龙翔桥

駅入口でEを押すと路線UIが開き、発見済みに関係なく4地区へ移動できます。
